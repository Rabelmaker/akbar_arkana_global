# Project Overview

WA Finance Report adalah SaaS multi-account untuk pencatatan dan pelaporan keuangan. Tahap saat ini membangun website dan REST API; WhatsApp, n8n, AI, dan Google Sheets belum dihubungkan.

Foundation yang tersedia: autentikasi Breeze, Vue 3 + Inertia, layout Materialize/Vuetify,
account utama per user, role/permission, Sanctum token support, activity log, dashboard
admin/user, API v1 dasar, dan lifecycle subscription.

Phase 3 menyediakan plan, trial otomatis, subscription history, aktivasi/perpanjangan/status,
expiry terjadwal, pembatasan mutasi melalui middleware, dan dashboard subscription admin.

Phase 4–7 menyediakan rekening dan kategori tenant, lifecycle transaksi yang aman, budget
berbasis realisasi transaksi, serta laporan keuangan terfilter dengan perbandingan periode,
arus kas, breakdown kategori/rekening, print view, dan ekspor CSV/XLSX/PDF.
